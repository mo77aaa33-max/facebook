Facebook Task - Flutter UI

Included:
- lib/main.dart
- assets/images/
- pubspec.yaml

Run:
1. Open this folder in VS Code or Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

The UI includes a social feed, stories, post cards, like interactions, and bottom navigation.
The screen recording must be captured on your own emulator/device after running the app.
